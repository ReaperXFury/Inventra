# 📦 Inventra

**Inventra** is a web-based inventory and store management application built on the [Laravel](https://laravel.com) framework. It streamlines daily retail operations by tracking sales, managing stock levels, handling store credit (Utang), and processing digital transactions such as GCash and E-Load.

---

## ✨ Features

- 🛒 **Sales Management**: Record transactions, process multiple payment methods (Cash, GCash), and track daily income.
- 📋 **Credit Tracking (Utang)**: Log customer credit records, monitor unpaid balances, and track payment schedules.
- 📊 **Inventory & Stock Control**: Track product quantities in real-time with automated low-stock warnings.
- 📱 **Digital Services**: Manage GCash cash-in/cash-out volume and mobile top-up (E-Load) records.
- ⚡ **Dashboard Overview**: Access aggregated daily metrics, sales summaries, and recent activity logs at a glance.

---

## 🛠️ Tech Stack

- ⚡ **Backend**: Laravel (PHP)
- 🎨 **Frontend**: Blade, Tailwind CSS, JavaScript
- 🗄️ **Database**: MySQL / MariaDB
- 🖼️ **Icons**: Lucide Icons
